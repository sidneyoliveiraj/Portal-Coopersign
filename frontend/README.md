# Frontend - Portal Coopersign

SPA em React + TypeScript (Vite) com componentes do Mantine.

## Rodando localmente

1. Subir a API (ver `backend/`) em `http://localhost:3000`
2. `npm install`
3. Copiar `.env.example` para `.env` se a API estiver em outro endereço
4. `npm run dev` e abrir `http://localhost:5173`
